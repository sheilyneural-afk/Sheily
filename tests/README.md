# Pruebas

- `architecture/`: cierre del registro y rutas prohibidas.
- `contracts/`: ejemplos válidos e inválidos.
- `integration/`: unión de plan y capacidad.
- `security/`: privilegios y separación.
- `recovery/`: transiciones y degradación.
- `chaos/`: fallo de monitores, parada y auditoría.
- `fixtures/`: datos completamente sintéticos.
