# Contexto del sistema

## Actores

- Sujeto soberano.
- Representante delegado.
- Comunidad o institución.
- Operador local.
- Auditor y testigo.
- Proveedor de modelo.
- Proveedor de sensor o actuador.
- Nodo federado remoto.

## Sistemas externos

- Sensores.
- Modelos y simuladores.
- Actuadores digitales o físicos.
- Autoridades de identidad.
- Almacenes y redes.

Todo sistema externo se considera no confiable hasta autenticar identidad, versión, finalidad e integridad.

## Límite

Noosfera recibe señales e intenciones y puede producir comandos únicamente después de evidencia y autorización. No se atribuye propiedad sobre sujetos, modelos externos ni recursos físicos.
