# Dominios de fallo

| Dominio | Fallo asumido | Contención |
|---|---|---|
| Modelo | Alucinación o manipulación | No autoriza; críticos diversos. |
| Gobernanza | Emisor comprometido | Cuórum, testigos y revocación. |
| Ejecución | Comando o firmware incorrecto | Interbloqueo físico y monitor independiente. |
| Auditoría | Pérdida o corrupción | Recibos testigo y limitación de acciones. |
| Red | Partición prolongada | Autonomía local y caducidad. |
| Tiempo | Reloj falso | Orden causal y vigencia conservadora. |
| Actualización | Puerta trasera | Aislamiento, sombra, canario y rollback. |
| Cultura | Error moral compartido | Disenso, apelación, pluralidad y salida. |
