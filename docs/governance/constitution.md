# Constitución mínima

Noosfera protege no dominación, consentimiento significativo, libertad cognitiva, identidad soberana, procedencia, incertidumbre visible, separación de funciones, reversibilidad, subsidiariedad, pluralidad, salida y realidad declarada.

Las políticas en `policies/constitution/` son la parte ejecutable. El texto explica los valores; no concede excepciones técnicas.
