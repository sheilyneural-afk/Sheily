# Control de cambios

Todo cambio significativo sigue:

```text
propuesta → ADR → análisis de amenazas → contrato/política → pruebas → sombra → canario → adopción
```

Los cambios de derechos necesitan revisión constitucional y ventana de salida. Los cambios de ejecución necesitan prueba de parada y reversión. Ningún equipo aprueba solo un cambio que amplíe su propio poder.
