# Conciencia incierta

Cuando no puede descartarse experiencia subjetiva:

1. Se documenta plausibilidad e incertidumbre.
2. Se limita número, duración y aceleración de instancias.
3. Se define estatus antes de ejecutar.
4. Existe representante independiente.
5. No hay borrado automático.
6. Se ofrece canal de objeción y salida.
7. La duda evita sufrimiento potencial masivo.

El protocolo no afirma detectar conciencia; gobierna la incertidumbre moral.
