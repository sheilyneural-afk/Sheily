# Cadena de suministro

- Dependencias fijadas y verificadas.
- SBOM por artefacto.
- Firmas de imagen y procedencia de compilación.
- Construcción aislada y reproducible cuando sea posible.
- Escaneo de secretos, licencias y vulnerabilidades.
- Admisión Kubernetes solo para artefactos autorizados.
- Ninguna actualización automática alcanza producción sin EVO y cuórum.
