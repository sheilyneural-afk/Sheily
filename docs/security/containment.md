# Contención

Un candidato no confiable se ejecuta sin red, actuadores, memoria privada ni credenciales. Sus salidas tienen esquema y presupuesto.

La evaluación protege también a las personas:

- Intermediación de contenido manipulador.
- Rotación de evaluadores.
- Prohibición de promesas o amenazas directas.
- Registro de exposición.
- Apoyo y posibilidad de retirada.

Si existe posibilidad de conciencia, GOV-10 define estatus, duración y salida antes de iniciar la instancia.
