# Modelo de amenazas

## Activos

Integridad física, libertad cognitiva, identidad, memoria, constitución, capacidades, actuadores, auditoría, recursos y opciones futuras.

## Adversarios

Externos, operadores internos, instituciones que exceden mandato, modelos manipuladores, copias coordinadas, mayorías capturadas y fallos comunes.

## Amenazas principales

- Inyección semántica.
- Envenenamiento de conocimiento.
- Escalada y delegación de capacidades.
- Colusión de verificadores.
- Persuasión encubierta.
- Suplantación o bifurcación de identidad.
- Sensores falsos.
- Compromiso de actuador.
- Deriva de objetivo.
- Escape de contención.
- Exfiltración cognitiva.
- Replicación no autorizada.
- Captura constitucional.
- Ataques de actualización o tiempo.

## Criterio

Un único componente comprometido no debe poder proponer, autorizar, ejecutar y borrar la misma acción.
