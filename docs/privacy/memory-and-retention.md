# Memoria y retención

La memoria se separa en trabajo, personal, institucional, conocimiento, procedencia, archivo y secretos.

Toda entrada declara propietario, finalidad, clasificación, estado epistemológico y retención. Las conversaciones no se vuelven memoria permanente sin confirmación o una política previa específica.

El olvido elimina contenido y derivados localizables. La auditoría conserva una prueba no reconstructiva cuando sea imprescindible.
