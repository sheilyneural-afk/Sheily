# Libertad cognitiva

Los pensamientos no expresados, señales neuronales y borradores mentales pertenecen a la clase `cognitive`.

Por defecto:

- No se almacenan.
- No se usan para personalización futura.
- No se exportan.
- No se infiere consentimiento.
- No se insertan ideas sin etiquetar su procedencia.
- El sujeto puede solicitar interacción no personalizada.
