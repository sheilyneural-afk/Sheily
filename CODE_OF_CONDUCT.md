# Código de conducta

Este proyecto protege la participación segura de personas y comunidades con perspectivas técnicas, culturales y cognitivas distintas.

No se permite acoso, coerción, discriminación, publicación de datos privados ni uso de la documentación para justificar la eliminación de derechos de grupos afectados.

Las críticas técnicas y filosóficas deben conservarse cuando sean relevantes para la seguridad, incluso si contradicen la posición mayoritaria.
