# Interfaces públicas

`openapi.yaml` describe solicitudes síncronas. `asyncapi.yaml` describe los buses. Las interfaces administrativas y los actuadores usan redes e identidades separadas.

Desde 0.2, OpenAPI incluye el recorrido local de Sheily y AsyncAPI registra `mission.event.v1`. FastAPI publica además una vista interactiva derivada del código en `/docs`; cualquier cambio debe conservar alineados código, esquemas y estas especificaciones.
