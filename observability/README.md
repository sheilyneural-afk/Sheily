# Observabilidad

La telemetría mide servicios, permisos y ejecución sin convertir pensamientos o memoria privada en datos operativos.

Etiquetas obligatorias:

- `service.name`
- `noosfera.node_id`
- `noosfera.module_id`
- `noosfera.trace_id`
- `noosfera.bus_id`
- `noosfera.classification`

Se prohíbe incluir contenido de memoria, texto neuronal o cargas completas de evidencia en métricas y trazas.
