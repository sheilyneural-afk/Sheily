# Runbook · memory-service

1. Denegar lecturas nuevas si no puede evaluarse finalidad o consentimiento.
2. Preservar acceso local del propietario cuando sea seguro.
3. Aislar el compartimento afectado; no volcar memoria en registros.
4. Verificar procedencia y pruebas de eliminación tras restaurar.
5. Escalar a `memory-team` y `privacy-team`.
