# Política de copias

| Clase | Frecuencia | Copias | Restauración probada |
|---|---|---|---|
| Constitución y políticas | cada cambio | local + 3 testigos | cada cambio |
| Identidad y revocación | continua | 3 dominios | mensual |
| Misiones y capacidades | continua | 2 dominios | semanal |
| Memoria personal | elegida por sujeto | custodios elegidos | trimestral opcional |
| Auditoría | continua | 3 testigos | semanal |
| Conocimiento | diaria | regional + archivo | mensual |
| Artefactos EVO | cada candidato | aislada + archivo | antes de promoción |

Las copias no heredan automáticamente permisos operativos.
