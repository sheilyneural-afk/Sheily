# experience-service

Aloja EXP-01..06 y constituye el backend funcional de Sheily 0.3. Expone conversaciones, documentos, misiones, memoria, auditoría y streaming SSE. Delega identidad, cognición, atestación, autorización y ejecución en procesos separados. No posee claves privadas de Identity, Agency, Governance o Audit.

No decide políticas, no firma capacidades y no ejecuta actuadores. La memoria se escribe únicamente tras consentimiento firmado y autorización de Governance.
