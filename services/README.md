# Servicios

Los 105 módulos lógicos se alojan en 14 dominios. Cada directorio contiene:

- `service.yaml`: manifiesto normativo.
- `main.py`: host de referencia ejecutable.
- `README.md`: responsabilidades y prohibiciones.

El host común expone salud y manifiesto. Las capacidades futuristas permanecen en estado `501` hasta conectar un proveedor evaluado; nunca se simula que una capacidad inexistente está implementada.
